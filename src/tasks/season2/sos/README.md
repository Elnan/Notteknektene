# S.O.S Game

A classic SOS game where players take turns placing S or O symbols on a 10x10 grid to complete SOS patterns.

## How to Play

1. **Objective**: Complete SOS patterns to score points and earn extra turns
2. **Gameplay**:
   - Players take turns placing either 'S' or 'O' in empty cells
   - Complete SOS patterns horizontally, vertically, or diagonally
   - Each SOS scores 1 point and grants an extra turn
   - Chain multiple SOS completions for big scores
3. **Game Structure**: Best of 3 rounds
4. **AI Opponent**: Simple AI that looks for SOS opportunities and makes strategic moves

## Features

- Clean, modern UI with green theme
- 10x10 game grid
- Symbol selection (S/O)
- Score tracking
- Round-based gameplay
- AI opponent
- Responsive design
- Rules modal
