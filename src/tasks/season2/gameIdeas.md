# Game Ideas for Season 2

## 1. Logic Circuit Builder

Players are given a set of logic gates (AND, OR, NOT, XOR, etc.) and a target output for a given set of inputs. They must arrange the gates to achieve the target output for all test cases. The fewer gates used, the better the score.

## 2. Cryptic Pathways

A grid-based puzzle where each cell contains a number or symbol. Players must find a path from start to finish, following a set of cryptic rules (e.g., the sum of numbers on the path must be a prime, or you can only step on cells that alternate even/odd).

## 3. Truth-Teller Tournament

Players are presented with a set of characters, each making statements about themselves or others. Some always tell the truth, some always lie. Players must deduce who is who and answer a final question (e.g., "Who stole the diamond?").

## 4. Sequence Sleuth

Players are given a sequence of numbers, shapes, or colors with a hidden rule. They must deduce the rule and predict the next item(s) in the sequence. The rules get progressively harder.

## 5. Gridlock

A logic puzzle where players must fill a grid with numbers or symbols so that each row, column, and region satisfies a set of constraints (e.g., Sudoku variants, KenKen, or Kakuro-style puzzles).

## 6. Alibi Analyzer

Players are given a set of suspects, timelines, and alibis. Using clues and cross-referencing statements, they must deduce who committed a crime, when, and how.

## 7. Logic Machine

Players are given a "machine" with a set of inputs and outputs. They must deduce the internal logic or rules of the machine by testing different input combinations and observing the outputs.

## 8. Island Isolation

A map of islands connected by bridges. Players must remove bridges so that each island is isolated, following a set of logical constraints (e.g., no two islands can have the same number of bridges, or certain islands must remain connected).

## 9. Cipher Challenge

Players are given encrypted messages and a set of clues about the cipher. They must deduce the encryption method and decode the message. Each level introduces a new cipher or twist.

## 10. Logic Tournament (Meta-Game)

A meta-puzzle where solving each individual game gives a piece of a larger logic puzzle. The first to solve the meta-puzzle (using clues from all games) wins the tournament.
