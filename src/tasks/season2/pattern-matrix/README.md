# Pattern Matrix

A modular, logic-based puzzle game where players deduce the missing figure in a 3x3 grid of patterned figures. Each figure consists of a circle with four segments and four squares, each cycling through three color states. The game features practice rounds, a timer, and a pause mechanic.

## Features

- 2 practice rounds with guided instructions
- 10 main rounds with logical patterns
- Interactive, color-cycling figures
- Timer, pause, reset, and confirm controls
- End screen with score and review
- Modular pattern logic for easy updates

## Modularity

Pattern generation and solution checking are handled in a separate logic file for easy swapping and versioning.
