### 1. Pattern Solver

**Status**: Ready for development  
**Priority**: High  
**Type**: Logic + Strategy

**Core Concept**: Grid-based puzzle where players place tiles to break hidden patterns, with progressive rule revelation.

**Mechanics**:

- 6x6 or 8x8 grid with colored tiles (Red, Blue, Green, Yellow)
- Hidden pattern rules (e.g., "No more than 2 red tiles in any row")
- Progressive feedback system reveals rules through trial and error
- Multiple difficulty levels with increasing rule complexity

**Scoring**:

- Efficiency (fewer moves = higher score)
- Discovery bonus (figuring out rules quickly)
- Perfect completion bonus

**Development Notes**:

- Clear mechanics, strong logic/strategy balance
- Fits existing game philosophy perfectly
- Ready to implement

## 🔄 In Development Queue

### 2. Chain Reaction

**Status**: Detailed concept  
**Priority**: Medium  
**Type**: Strategy + Planning

**Core Concept**: Place dominoes strategically to create longest chains, with rules that evolve based on moves.

**Mechanics**:

- 8x8 grid with obstacles and special tiles
- Multiple domino types (standard, bounce, split, delay)
- Dynamic rule system that adds new rules after each move
- Strategic planning required as rules change

**Scoring**:

- Chain length (primary metric)
- Rule adaptation bonus
- Efficiency points

**Development Notes**:

- Unique dynamic rules system
- Requires forward thinking and adaptation
- More complex to implement than Pattern Solver

## 📋 Development Guidelines

### Priority Criteria

1. **Feasibility**: How easy is it to implement?
2. **Uniqueness**: Does it offer something different?
3. **Engagement**: Will it challenge intelligent users?
4. **Alignment**: Does it fit the Notteknektene philosophy?

### Implementation Order

1. **Pattern Solver** (Ready to start)
2. **Chain Reaction** (After Pattern Solver)
3. **The Keeper** (Enhancement of existing concept)
4. **Schoolyard Champion** (If we want to experiment with hybrids)

### Notes

- Focus on one game at a time
- Each game should offer unique strategic/logic challenges
- Maintain consistency with existing game quality and style
- Consider user feedback and learning curves
